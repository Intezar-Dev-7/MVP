# Error – Developer Networking & Collaboration App

Error is a developer-focused networking platform (currently in MVP stage) built to help developers connect, collaborate, and build projects together. Unlike traditional social media apps, Error focuses on meaningful interactions and professional growth.

---

## 🚀 Features

* 🔐 User Authentication (Firebase)
* 📝 Create, Update, Delete, and Fetch Posts (CRUD)
* 📰 Personalized Feed displaying user posts
* 🔍 Discover Screen to explore other developers
* 🤝 Send and receive connection requests
* 💬 1:1 Chat functionality
* 👤 Profile Management (Edit profile details)
* 🔗 Add external links:

  * GitHub
  * Portfolio
  * LinkedIn
  * Instagram

---

## 🧠 Purpose

* Focused on **networking and collaboration**
* Helps developers **showcase their projects**
* Encourages **learning and building together**
* Designed as an **MVP with core essential features**

---
